# 搜查面板开关过渡

本目录提供局内搜查面板打开、关闭、正常显示及返回局内的素材。画面中的安全箱为空。

- 无损 WebP 直接来自原录像顺序解码，帧号从0开始。`帧0200`为正常面板，`帧0206/0207`为关闭过渡，`帧0222`已回到局内；`帧1103/1105`为打开过渡，`帧1114`已到位。
- `关闭过程.mp4`为原帧192–231，`打开过程.mp4`为1086–1125，均60fps、1920×1080并遮挡UID。短片采用有损重编码，仅用于核对时序；精确图像识别使用无损WebP。
- `识别记录.json`保存28张仍通过面板文字条件的原版异常帧：关闭过渡未知4帧、误占用6帧；打开过渡未知7帧、误占用11帧。此为离线识别记录，不是自动输入执行记录。`local`字段为被撤回的归一化加灰度试验方案，不能作为当前实现结果。
- 录像中的再次打开均由玩家重新按F触发，也包含主动关闭。不得将所有关闭都标为受击，也不得将重新打开描述为自行恢复。
- `来源.json`记录源文件名、SHA256、裁片帧范围和归档文件摘要，不依赖本机私人路径。

判据：开关过渡不能参与物品决策；正常空箱、有物和锁定格的布局仍可操作。自动化中断策略和已知限制见主仓 `docs/develop/zzz/application/bagel.md` 的“搜查面板可操作性”。

## 识别区域与离线记录

`局内ROI.png`、`仓库ROI.png` 与 `局内与仓库ROI对照.png`按对应代码的实际采样范围绘制。ROI坐标见 `ROI坐标.json`。这些图展示格子识别范围，不是新增面板稳定区或格框搜索范围；图中的分类统计为素材对照，当前判据以主仓代码为准。

`原版与PR逐帧记录.json`保留3209帧的原格子与PR格子输出；`面板门槛逐帧记录.json`为当前位置和静态区门槛回放。28张文字通过的异常帧均未通过面板门槛。1314张高模板相似度参考帧中也有开关边沿及揭示动画引起的短暂等待，模板相似度不是业务放行条件。

`采样等待记录.json`在所列面板区间按0.3秒采样，覆盖18种起始相位，最多连续等待3次，没有达到第6轮停止上限。该回放不模拟OCR和游戏输入。完整源录像未纳入测试仓；故障像素、代表正常帧和两段时序片段已归档。以上均不能替代完整自动化的实机验收。
